ACCOUNTS V1.4.6 — TRUENAS DEPLOYMENT
=====================================

1. Upload the complete V1.4.6 contents to the main branch of:
   https://github.com/valianktni1/march-weddings-by-mark-accounts

2. Run in the TrueNAS shell:

ACCOUNTS_COMPOSE=/mnt/apps/dockge/data/accounts-2026-use/compose.yaml

docker compose -f "$ACCOUNTS_COMPOSE" build --no-cache backend frontend
docker compose -f "$ACCOUNTS_COMPOSE" up -d

for ATTEMPT in $(seq 1 30); do
  ACCOUNTS_HEALTH=$(curl -sS http://127.0.0.1:30053/api/health 2>/dev/null || true)
  if printf '%s' "$ACCOUNTS_HEALTH" | grep -q 'manual-booking-pdf-import-v1.4.6'; then
    printf '%s\n' "$ACCOUNTS_HEALTH"
    break
  fi
  printf 'Waiting for Accounts V1.4.6 — attempt %s/30\n' "$ATTEMPT"
  sleep 2
done

docker compose -f "$ACCOUNTS_COMPOSE" ps

Expected build:
2026.08.19-manual-booking-pdf-import-v1.4.6

3. Test WBM01205 manually:

- Open Accounts > Invoices > New Invoice.
- Choose WBM01205.pdf.
- Confirm the populated information before saving.
- Enter the venue because it is not printed on the invoice.
- Check the pre-filled £100 payment date; the PDF prints the payment but not its exact date.
- Leave Add to Income switched OFF when the payment already exists in bank transactions.
- Press Import WBM01205.
- Open its PDF from the invoice list and confirm the original BookingSystem invoice is retained.

No database migration is required.
Booking integration can remain disabled; this release supports the manual PDF workflow.
