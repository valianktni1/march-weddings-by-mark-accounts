ACCOUNTS V1.4.8 - TRUENAS DEPLOYMENT
====================================

1. Upload the complete extracted release to the main branch of:
   https://github.com/valianktni1/march-weddings-by-mark-accounts

2. In the TrueNAS shell, run these commands exactly:

ACCOUNTS_COMPOSE=/mnt/apps/dockge/data/accounts-2026-use/compose.yaml

docker compose -f "$ACCOUNTS_COMPOSE" build --no-cache backend frontend
docker compose -f "$ACCOUNTS_COMPOSE" up -d backend frontend

docker compose -f "$ACCOUNTS_COMPOSE" ps
curl -fsS http://127.0.0.1:30053/api/health
echo

Expected build:
2026.08.19-paid-personally-expenses-v1.4.8

AFTER DEPLOYMENT
----------------
1. Open Expenses and find each genuine manual expense paid with a personal card or personal funds.
2. Click the pencil icon.
3. Tick "Paid personally / personal credit card".
4. Leave "Exclude from tax totals" unticked.
5. Save the expense and repeat for any other genuinely personally paid expenses.
6. Return to Tax Year Close. The false duplicate-bank blocks will be gone, while the expenses remain in the allowable total.

IMPORTANT
---------
- Keep BOOKING_INTEGRATION_ENABLED set to "false" in the Accounts compose file.
- No database migration command is required.
- Existing records are not automatically reclassified or removed.
- Do not mark a genuine duplicate as paid personally; delete or link the duplicate instead.
