WEDDINGS BY MARK ACCOUNTS V1.4.2 - TRUENAS DEPLOYMENT
======================================================

This is a cumulative release. If V1.4.1 has not yet been deployed, upload this
V1.4.2 package instead; it includes all previous V1.4 and V1.4.1 work.

1. Upload this complete release to the root of:
   https://github.com/valianktni1/march-weddings-by-mark-accounts

2. Take a safe MongoDB backup:

ACCOUNTS_CANCELLED_PDF_BACKUP=/mnt/nextcloud/accounts-2026-saved-data/backups/accounts-before-cancelled-invoice-stamp-v1.4.2-2026-08-18.archive.gz

if [ -e "$ACCOUNTS_CANCELLED_PDF_BACKUP" ]; then
  echo "STOP: Accounts backup already exists — nothing was overwritten"
else
  docker exec accounts-2026-db sh -lc 'mongodump --quiet --username "$MONGO_INITDB_ROOT_USERNAME" --password "$MONGO_INITDB_ROOT_PASSWORD" --authenticationDatabase admin --db weddings_by_mark_accounts_2026 --archive --gzip' > "$ACCOUNTS_CANCELLED_PDF_BACKUP"
fi

ls -lh "$ACCOUNTS_CANCELLED_PDF_BACKUP"
gzip -t "$ACCOUNTS_CANCELLED_PDF_BACKUP" && echo "Accounts backup integrity OK"

3. Rebuild Accounts:

ACCOUNTS_COMPOSE=/mnt/apps/dockge/data/accounts-2026-use/compose.yaml

docker compose -f "$ACCOUNTS_COMPOSE" down
docker compose -f "$ACCOUNTS_COMPOSE" build --no-cache backend frontend
docker compose -f "$ACCOUNTS_COMPOSE" up -d

4. Verify:

docker compose -f "$ACCOUNTS_COMPOSE" ps
curl -fsS http://127.0.0.1:30053/api/health
echo

Expected build:
2026.08.18-cancelled-invoice-stamp-v1.4.2

5. Open WBM02419 from Accounts and download its PDF. The existing stored PDF
   will automatically regenerate as a native Weddings By Mark cancelled-wedding
   record. Other existing invoice PDFs are upgraded safely when first opened or
   included in a Tax Year evidence pack.

No YAML changes are required.
