WEDDINGS BY MARK ACCOUNTS V1.4.1 - TRUENAS DEPLOYMENT
======================================================

1. Upload this complete release to the root of:
   https://github.com/valianktni1/march-weddings-by-mark-accounts

2. Take a safe MongoDB backup:

ACCOUNTS_CASH_BACKUP=/mnt/nextcloud/accounts-2026-saved-data/backups/accounts-before-cash-payments-v1.4.1-2026-08-18.archive.gz

if [ -e "$ACCOUNTS_CASH_BACKUP" ]; then
  echo "STOP: Accounts backup already exists — nothing was overwritten"
else
  docker exec accounts-2026-db sh -lc 'mongodump --quiet --username "$MONGO_INITDB_ROOT_USERNAME" --password "$MONGO_INITDB_ROOT_PASSWORD" --authenticationDatabase admin --db weddings_by_mark_accounts_2026 --archive --gzip' > "$ACCOUNTS_CASH_BACKUP"
fi

ls -lh "$ACCOUNTS_CASH_BACKUP"
gzip -t "$ACCOUNTS_CASH_BACKUP" && echo "Accounts backup integrity OK"

3. Rebuild Accounts:

ACCOUNTS_COMPOSE=/mnt/apps/dockge/data/accounts-2026-use/compose.yaml

docker compose -f "$ACCOUNTS_COMPOSE" down
docker compose -f "$ACCOUNTS_COMPOSE" build --no-cache backend frontend
docker compose -f "$ACCOUNTS_COMPOSE" up -d

4. Verify:

docker compose -f "$ACCOUNTS_COMPOSE" ps
curl -fsS http://127.0.0.1:30053/api/health
echo

Expected build:
2026.08.18-cash-payment-reconciliation-v1.4.1

5. After both apps are deployed, keep automatic sync off and use the existing
   manual Booking-to-Accounts sync when required.

No YAML changes are required.
